# Restaurant app modules

Modules feature-based rahenge, role-based nahi.

- `auth`: login, forgot password, session basics
- `dashboard`: role-wise home widgets
- `menu`: categories, items, availability
- `tables`: tables and QR setup
- `customer-ordering`: public QR order flow
- `orders`: order list, details, status
- `kitchen`: kitchen display board
- `waiter`: waiter-focused table/order actions
- `billing-pos`: bill creation and POS flow
- `payments`: payment records and paid/unpaid status
- `customers`: CRM/customer profiles
- `analytics`: reports and summaries
- `settings`: restaurant profile, staff, permissions, printer/tax settings
